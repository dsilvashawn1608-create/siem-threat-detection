# Demo pcap

`demo-lab-traffic.pcap` is synthetic traffic generated by `generate_demo_pcap.py`
(requires `pip install scapy`). It's crafted to trigger every rule in
`../rules/local.rules` exactly once:

| SID     | Rule                          | Packet                                  |
|---------|-------------------------------|------------------------------------------|
| 1000001 | ICMP Test Rule Triggered      | 1 ICMP echo, 10.0.0.5 -> 10.0.0.10       |
| 1000002 | SSH Brute Force Attempt       | 4x TCP SYN to :22 within the rule's 60s window |
| 1000003 | TCP SYN scan detected         | 1 TCP SYN to :80                         |
| 1000004 | SMB Access Attempt            | 1 TCP SYN to :445                        |
| 1000005 | Suspicious DNS Query Volume   | 1 UDP packet to :53                      |
| 1000006 | Possible C2 Beacon Port       | 1 TCP SYN to :4444                       |

Regenerate it with:

```bash
cd snort/pcaps
python3 generate_demo_pcap.py
```

Validate against a real Snort binary (what was done to build
`backend/tests/fixtures/real_snort_alert.log`, the fixture the backend's
test suite parses against):

```bash
sudo apt-get install -y snort      # Ubuntu 24.04 ships 2.9.20, not Snort 3
cd snort
snort -c snort.conf -r pcaps/demo-lab-traffic.pcap -l /tmp/snort-test-log -A fast -N
cat /tmp/snort-test-log/alert
```
